# Surface Agent Guidance

For any task that authors, extends, renders, or verifies Surface interfaces,
read and follow `.agents/skills/building-surface-interfaces/SKILL.md`. Load the
referenced authoring, architecture, or verification file that matches the task.

Treat `lib/schemas.ts`, `lib/catalog.ts`, `lib/domain.ts`, and the deterministic
compiler as sources of truth when skill prose and implementation differ.
